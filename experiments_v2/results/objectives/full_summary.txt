
=== NOTE ===
- Primary family (12 tests) = the four two-period 1-day tests (Nifty 50 and Bank, Periods A and B) x {Sharpe, Sortino, Treynor}, matched metric, DTW vs Standard. This family was chosen AFTER seeing the earlier Sharpe results. Bonferroni and Benjamini-Hochberg are applied to the two-sided p-values of these 12 only; everything else is descriptive.
- Treynor is a side result: the Treynor objective uses the covariance only through the betas, so DTW vs Standard Treynor compares beta estimates. DTW betas are negatively correlated with sample betas (see beta diagnostic).
- Primary DTW = FastDTW (radius 1, |x-y| cost) on raw daily log returns. FastDTW is not continuous in its input (1e-12 relative perturbations change ~7% of pairwise distances by up to 1%), so re-downloaded data moves DTW Sharpe by up to ~0.001; Standard results are unaffected.
- rf = MAR = 0; annualisation sqrt(252/h); horizons = non-overlapping blocks of daily log returns; bootstrap: paired moving-block, 5000 resamples, block 20 observations, seed 20261021, days resampled jointly for both portfolios and all metrics; p_one = P(boot diff <= 0); p_two = 2 min(p_one, 1 - p_one).
- Treynor metric = annualised mean / average training-period sample beta (vs ^NSEI) of the portfolio held each day.
- Nifty Midcap 100 (expanding window) not rerun: its regime index is no longer available from Yahoo. Original Sharpe result kept, labelled NOT REPRODUCED.
